# ATLAS

Тематический справочник-навигатор.
Далеко не идеален, но уже в некотором смысле достаточен.

Выпускается в нескольких форматах, но основной – pdf.

Issues открыты, но помните о своей приватности.

## Сборка

```sh
typst compile Атлас.typ         # PDF
cd conveyer && uv run build.py  # EPUB, FB2, RTF (нужны typst и pandoc)
```
